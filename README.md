# Hotel Booking Management System

## Description

A Java Console-based Hotel Booking Management System that allows users to manage hotel room bookings.

## Features

- View Rooms
- Search Room
- Book Room
- Cancel Booking
- View Bookings
- View Statistics
- Input Validation
- Exception Handling

## Technologies

- Java
- OOP
- ArrayList
- Scanner
- Exception Handling

## Concepts Used

- Classes & Objects
- Encapsulation
- Constructors
- Collections
- ArrayList
- Methods
- Exception Handling
- Searching

## How to Run

1. Compile all Java files.
2. Run `Main.java`.
3. Follow the console menu.
